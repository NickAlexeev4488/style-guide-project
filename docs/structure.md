# Структура стайлгайда

Стайлгайд для проекта MkDocs состоит из следующих разделов:

1. Назначение и область применения.
2. Структура проекта MkDocs.
3. Правила создания страниц.
4. Заголовки и навигация.
5. Требования к языку и терминологии.
6. Оформление списков и таблиц.
7. Оформление команд и кода.
8. Работа со ссылками и изображениями.
9. Требования доступности.
10. Локальная проверка и сборка.
11. Проверка и публикация изменений.
12. Чек-лист перед публикацией.

## Структура проекта

```text
style-guide-project/
├── docs/
│   ├── index.md
│   ├── rules.md
│   ├── structure.md
│   ├── style-guide.md
│   ├── accessibility.md
│   ├── testing.md
│   └── assets/
│       └── images/
├── mkdocs.yml
├── CONTRIBUTING.md
└── README.md
```

## Назначение файлов

| Файл | Назначение |
| --- | --- |
| `docs/index.md` | Главная страница документации |
| `docs/rules.md` | Краткий набор основных правил |
| `docs/structure.md` | Описание структуры стайлгайда и проекта |
| `docs/style-guide.md` | Полное руководство по стилю |
| `docs/accessibility.md` | Правила доступности текста и изображений |
| `docs/testing.md` | Примеры применения и оценка правил |
| `CONTRIBUTING.md` | Порядок внесения изменений и ревью |
| `README.md` | Описание репозитория и локального запуска |

Такая структура позволяет сначала познакомиться с проектом, затем изучить краткие правила и перейти к полному руководству.
