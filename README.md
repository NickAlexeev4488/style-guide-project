## Локальный запуск

1. Установите MkDocs:

   ```bash
   pip install mkdocs
   ```

2. Перейдите в корневой каталог проекта.

3. Запустите локальный сервер:

   ```bash
   mkdocs serve
   ```

4. Откройте адрес `http://127.0.0.1:8000` в браузере.

## Проверка сборки

Перед публикацией выполните:

```bash
mkdocs build --strict
```

Сборка должна завершиться без ошибок и предупреждений.
