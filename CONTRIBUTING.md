# Как внести изменения

Этот документ описывает процесс изменения руководства по стилю.

## Предложение изменения

1. Проверьте, что похожее правило ещё не описано в документации.
2. Сформулируйте проблему и объясните, зачем требуется изменение.
3. Создайте отдельную ветку от актуальной ветки `main`.
4. Измените существующую страницу или добавьте новую страницу в каталоге `docs`.
5. При добавлении страницы обновите навигацию в `mkdocs.yml`.
6. Проверьте документацию локально.
7. Создайте Pull Request и опишите выполненные изменения.

## Название ветки

Название ветки должно кратко описывать изменение:

```text
docs/add-accessibility-rules
docs/update-code-examples
fix/broken-links
```

## Оформление коммитов

В проекте используется соглашение Conventional Commits.

Примеры:

```text
docs: add accessibility guidelines
docs: update installation instructions
fix: correct broken navigation link
chore: configure documentation linting
```

Один коммит должен содержать одно логически завершённое изменение.

## Требования к Pull Request

В описании Pull Request укажите:

- цель изменения;
- изменённые или добавленные страницы;
- способ проверки результата;
- известные ограничения.

Перед объединением изменений другой участник должен проверить Pull Request и оставить содержательные комментарии.

## Процесс ревью

Рецензент проверяет:

- понятность и достоверность текста;
- соблюдение стайлгайда;
- правильность структуры заголовков;
- единообразие терминов;
- корректность команд и примеров;
- работу ссылок и изображений;
- успешную сборку MkDocs.

Автор отвечает на комментарии, вносит необходимые исправления и отправляет изменения на повторную проверку. После одобрения Pull Request объединяется с веткой `main`.

## Локальная проверка

Установите MkDocs:

```bash
pip install mkdocs
```

Запустите локальный сервер:

```bash
mkdocs serve
```

Перед отправкой Pull Request выполните строгую сборку:

```bash
mkdocs build --strict
```

## Добавление нового раздела

1. Создайте Markdown-файл в подходящем каталоге внутри `docs`.
2. Добавьте один заголовок первого уровня.
3. Заполните страницу в соответствии со стайлгайдом.
4. Добавьте страницу в раздел `nav` файла `mkdocs.yml`.
5. Проверьте навигацию и ссылки через `mkdocs serve`.
6. Выполните `mkdocs build --strict`.
